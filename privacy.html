プライバシーポリシー

  • このアプリは所有者本人だけが使う個人用のアプリです。
  • 使用する権限は Google ドライブの drive.file(このアプリが作成したファイルとフォルダだけを扱う権限)のみです。
  • このアプリが作成したファイル以外のデータを読み取りません。データを第三者に提供・販売・共有しません。
  • 認証情報は所有者の GitHub リポジトリの暗号化された secret にのみ保存します。

Privacy Policy

  • This app is used only by its owner for personal purposes.
  • It requests only the drive.file scope (access limited to files and folders created by this app).
  • It does not read any other data and does not share, sell, or transfer data to third parties.
  • Credentials are stored only as encrypted secrets in the owner's GitHub repository.
